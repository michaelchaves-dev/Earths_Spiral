# Earths_Spiral
Galactic Corkscrew is an interactive, mobile-friendly Solar System trajectory simulator designed to visualize planetary orbital motion while the Solar System itself moves through space.  Instead of only showing Earth repeatedly circling a stationary Sun, the simulator changes the frame and allows user to see how orbital motion w -> motion etc
